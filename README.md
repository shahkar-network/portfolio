# Portfolio

Full-stack applications and AI agent workflows. The main tool is Cursor, with Codex and Claude Code as well, including MCP.

The stack follows the product: web, mobile, and Windows desktop, using OpenAI, Anthropic, Gemini, Google Cloud, or AWS.
